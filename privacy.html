How the tool itself works

The Python editor and its output run entirely in your browser using a technology called Pyodide (Python compiled to WebAssembly). Code you write and run in the editor is not sent to any server — execution happens locally on your device. Nothing you type is stored, logged, or transmitted by this site's own code.

Third-party services

This site may use the following third-party services, each with its own privacy practices:

  • Google Fonts — loads typefaces from Google's servers, which may log requests including IP address. See Google's Privacy Policy.
  • jsDelivr CDN — hosts the Pyodide runtime files this site loads. See jsDelivr's Privacy Policy.
  • Google AdSense — may use cookies to serve ads based on your visits to this and other sites. You can opt out of personalized advertising by visiting Google Ads Settings. See how Google uses data from partner sites.

Cookies

This site's own code does not set cookies. Third-party services listed above (particularly ad networks, if enabled) may set their own cookies in your browser to serve and measure ads.

Analytics

This site uses Google Analytics to understand how many people visit and how they use the page (e.g. page views, approximate location based on IP, device and browser type, time spent on the page). Google Analytics does not collect names, emails, or anything you type into the code editor. See Google's Privacy Policy for details on how this data is handled.

Children's privacy

This site is not directed at children under 13 and does not knowingly collect personal information from them.
